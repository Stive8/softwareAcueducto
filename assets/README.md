# Ícono de la Aplicación

Coloca aquí un archivo `icon.png` (256x256 o superior) para que aparezca como ícono de la aplicación.

Puedes generar un ícono profesional usando:
- https://www.favicon-generator.org/
- https://www.icoconverter.com/

El archivo debe llamarse `icon.png` y estar en esta carpeta.
